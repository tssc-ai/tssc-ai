# Roadmap & Help Wanted

Welcome to the TSSC (Theory of the Continuous Semantic Space) repository! 

This codebase currently establishes the **foundational mathematical and dynamical claims** of the theory (the base experiments). The immediate next frontier is building the **Full Toy Model**, which will exercise the entire lifecycle of a semantic perturbation, observation, and structural adaptation. 

We are actively looking for collaborators to bring this to life. If you want to put your hands on the code and contribute to the next generation of semantic architectures, here is exactly where we need help.

---

## 🚩 Milestone 1: The Full Perturbation Cycle
**Goal**: Implement the complete lifecycle of a single semantic event, stopping just before ontogenetic transformation.

- [ ] **Source Projection**: Project an external context $C$ onto the observable vocabulary $\mathcal{V}_{\text{lex}}$.
- [ ] **Field Propagation**: Compute the steady-state semantic field $\Psi$ via the contraction equation on the dual medium (magnitude $\mathbf{M}$ and signed weights $\mathbf{W}$).
- [ ] **Endogenous Observation**: Apply the parameter-free operator $\varepsilon^*(X) = \frac{\sum x^2}{\sum x}$ to cut the dissipative tail and isolate the Active Support.
- [ ] **Parametric Regime**: Implement the dual accumulators to update $\mathbf{M}$ and $\mathbf{W}$ via dynamic PMI, physiological forgetting, and trace accumulation.

## 🚩 Milestone 2: Genesis on Planted Causes
**Goal**: Demonstrate that the network can autonomously discover hidden structural commonalities and generate new latent units from scratch.

- [ ] **Synthetic Environment**: Create a synthetic dataset of contexts generated by a set of "planted" (hidden) ground-truth causes.
- [ ] **Tension Detection**: Implement the continuous monitoring of Negative Cut Tension. Detect when parametric sedimentation is no longer sufficient to resolve the network's frustration.
- [ ] **Rank-1 Factorization**: Implement the local, non-negative extraction of a candidate latent factor from the frustrated region.
- [ ] **Double Commit Test**: Implement the thermodynamic safety checks (energy extraction and complexity cost). If passed, permanently add the new latent node $\zeta$ to the ontology $\mathcal{V}_{\text{lat}}$ (Genesis).

## 🚩 Milestone 3: Mitosis and Coalescence
**Goal**: Implement the structural reorganization mechanisms for overloaded or redundant units.

- [ ] **Mitosis (Differentiation)**: Detect when a single latent unit is forced to respond to mutually exclusive contexts (bimodal restricted signatures) and split the unit into two distinct nodes.
- [ ] **Coalescence (Fusion)**: Detect when two distinct latent units show chronically identical activation signatures over time, and merge them to reduce redundancy.
- [ ] **Apoptosis**: Refine the physiological forgetting to completely dissolve units that fall below a critical structural mass.
